# v3.7.4 核心流程修复与验证

## 修复

- DNS64 改为显式启用，默认不修改系统 DNS；缺少 ping 或 ICMP 被过滤不再触发修改。
- Xray、Sing-box 和 Snell v5/v6 更新先下载并验证，再备份和替换；失败恢复旧文件和原运行状态。统计版 Sing-box 更新同时备份数据库。
- 配置重建统一使用候选文件、核心原生检查、安装、受影响核心重启及健康检查；任何端口生成失败均拒绝应用并回滚。原先停止的核心保持停止。
- 单端口卸载保留其他端口的共享证书，只清理选定协议和端口的 NAT；生成的 HY2/TUIC NAT 脚本支持单对象和数组。
- 数据库修改到回滚全程持锁，支持嵌套调用和无 flock 环境，防止失败回滚覆盖并发写入。
- Xray/Sing-box 读取上下行累计计数，用量与 checkpoint 原子保存；失败可重试，重复同步不重复计费，读取前后核对核心进程代次。
- 停用 SS2022 最后一个用户时关闭该端口，避免空用户列表接受服务端密钥；到期停用失败返回错误，不发送成功通知。
- 用户修改、启动、核心切换、WARP 配置重建接入统一生成与检查流程，移除旧的重复用户配置代码；新生成 watchdog 尊重手动暂停。

## 使用与限制

已有安装可使用菜单检查更新，或下载新版脚本后执行 `sh vless-server.sh`。无需卸载重装；修改配置时会保存私有备份并校验候选配置。配置变更需要重启所属核心，同核心的其他连接会短暂中断。

- 本次 TCP/UDP 路由测试使用本地 HTTP/echo 和临时 relay，未复测 Global-Home、外部 DNS、外部出口 IP 或 IPv6 网络连通性。
- Alpine/OpenRC、真实 Snell 升级与防火墙修改采用回归模拟，未在对应真实环境重做。HY2/TUIC 本次进行了原生配置检查；按用户安排，真实 QUIC 客户端连通性测试暂缓。
- 断电或核心崩溃可能丢失最后一次同步之后的内存计数；备份需按服务器磁盘空间维护。
- 正在运行的旧 watchdog 不会自动加载新逻辑；需在维护时重新生成并启用。
- 旧的 TLS 分享链接仍使用常见客户端的 `allowInsecure` 导入参数；直接生成新版 Xray 客户端配置时需验证/信任证书或使用核心支持的证书固定参数。未改变历史链接以避免破坏现有客户端导入。
